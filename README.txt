
# Student Expense Tracker

## Project Description
A simple Python-based application that helps
students record daily expenses and calculate
their total spending.

## Features
1. Add Expense
2. View Expenses
3. Calculate Total Expense
4. Category-wise Summary
5. Clear All Expenses

## Technologies Used
- Python

## Installation

Install required library:

pip install -r requirements.txt
